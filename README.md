# Coffeeshop with Django

Exploring Django by building a simple Coffeeshop Project

## Core Features

### Cafe Management:

- Add, edit, and view cafes.
- View lists and details of cafes.

### Menu Management:

- Add, edit, and view menu items for each cafe.
- View lists and details of menu items.

### Order Management:

- Create orders and order items.
- View lists and details of orders and order items.

### Customer Management:

- Add, edit, and view customer information.
- View lists and details of customers.

### Employee Management:

- Add, edit, and view employee information.
- View lists and details of employees.

### Review Management:

- Add, edit, and view reviews for cafes.
- View lists and details of reviews.

### Payment Management:

- Record payments for orders.
- View lists and details of payments.

### Offers and Discounts:

- Add, edit, and view special offers and discounts for cafes.
- View lists and details of offers.

## URL Routing

- The main URLs are configured in cafe/urls.py.
- Additional URLs for the main app are defined in main/urls.py.

## Models

The data schema and relationships are defined in main/models.py.

## Views

The views and functionalities are implemented in main/views.py.
